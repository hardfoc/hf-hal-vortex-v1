void vortex::bsp::host::SetI2cPresent ( uint8_t  address,
bool  present = true 
)
noexcept

Simulate a chip that acknowledges address on the I2C bus (probe and scan see it).

Call before the device is added (before EnsureInitialized()). A device added at an address that is not present NACKs every transfer, as on a board without that chip; a test that wants a chip model sets one on I2cAt(address) after marking it present.
