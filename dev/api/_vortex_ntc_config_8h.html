Detailed Description

Board NTC thermistor wiring: which TMC9660 ADC input it is on and how the handler is set up.

The board NTC sits on TMC9660 AIN3 (ADC_TMC9660_AIN3 in the pin map). Every TMC9660 ADC channel is served by one shared Tmc9660AdcWrapper, which routes by hardware channel id at read time, so the NTC handler must be told the channel explicitly: the handler's default (adc_channel = 0) would read AIN0. The channel here is read from the pin map, not repeated.

Ownership: constants only. Thread safety: none needed. MCU-free.
