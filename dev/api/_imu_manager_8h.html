Detailed Description

IMU device management for the HardFOC Vortex V1 platform.

Manages multiple BNO08x IMU devices. The onboard IMU (index 0) is auto-created via CommChannelsManager I²C; up to three external IMU devices (indices 1–3) can be added at runtime over I²C or SPI. Includes GPIO interrupt support for data-ready signalling.

IMU manager error codes for consistent error reporting.
