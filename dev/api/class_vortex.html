◆ EnsureInitialized()

bool Vortex::EnsureInitialized ( )
noexcept

Bring the managers up in dependency order (idempotent).

Fail-closed: if a required manager (NVS, comms, GPIO, LEDs) fails, every manager that did come up is shut down again in reverse order, GetLastError() says why, and the call returns false; nothing is left half-initialised. Best-effort managers (motors, ADC, IMU, encoders, temperature) that fail become warnings (GetSystemWarnings()). If the motor controller does not come up, the TMC9660 driver-enable line is driven inactive.

Returns
true when every required manager is up.
