Detailed Description

Singleton manager for all temperature sensors on Vortex V1.

Manages three temperature sources: ESP32 internal sensor, NTC thermistor via TMC9660 AIN3, and TMC9660 internal chip temperature. Sensors are registered in a fixed-size array; readings are returned in Celsius or Fahrenheit.

Note
Call EnsureInitialized() once before any reads. All public methods are thread-safe (guarded by an internal RTOS mutex).
