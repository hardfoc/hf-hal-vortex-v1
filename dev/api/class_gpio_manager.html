Detailed Description

Singleton managing GPIO pins across ESP32, PCAL95555 I/O expander, and TMC9660 controllers.

Registers all GPIO, USER, ADC, and SPI category pins from the X-MACRO pin config. Handles three chip types:

  • ESP32_INTERNAL: native ESP32 GPIO
  • PCAL95555: 16-bit I²C I/O expander (lazy-init from CommChannelsManager)
  • TMC9660_CONTROLLER: motor driver GPIOs (routed via MotorController) Thread-safe via RtosMutex.

◆ RegisterTmc9660BridgePinsIfNeeded()

void GpioManager::RegisterTmc9660BridgePinsIfNeeded ( )
noexcept

After MotorController::CreateOnboardDevice(), register TMC9660 GPIO17/18 in the table.

Vortex initializes GPIO before motors, so Tmc9660Handler does not exist during the first EnsureInitialized() scan. Call this from Vortex::InitializeMotors() once the onboard handler exists; idempotent if pins are already registered.

Those pins are the same physical lines as PCAL_TMC_GPIO17_EXP_IN / PCAL_TMC_GPIO18_EXP_IN (expander inputs P1–P2): use the PCAL aliases for passive read without TMCL; use TMC_GPIO17 / TMC_GPIO18 for driver-backed direction and output updates over SPI/UART.
