Detailed Description

ESP32-C6 implementation of the Vortex board binding (VortexBoardBind.h).

The only translation unit of the HAL that constructs ESP32 peripherals: EspSpiBus, EspI2cBus, EspUart, EspCan, EspGpio, EspNvs, EspTemperature, and the WS2812 status LED through hf-core's Ws2812Handler. Every object lives in function-local static storage (std::optional, emplaced on Open and reset on Close), so the binding itself allocates nothing; the ESP-IDF drivers underneath allocate their queues inside Open.

Thread safety: none; each function is called by its owning manager under that manager's lock.
