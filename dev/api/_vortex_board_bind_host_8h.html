Detailed Description

Host implementation of the Vortex board binding, over the hf-core host mocks.

Built only by tests/host. Every bus, pin and store the managers open through VortexBoardBind.h is an hf::host::Mock* object that a test can reach through the accessors below to script it (responders, injected faults) and inspect what the manager sent. Reset() closes everything and clears the scripted failures; call it at the start of each test case.

Thread safety: none (host tests are single-threaded).
