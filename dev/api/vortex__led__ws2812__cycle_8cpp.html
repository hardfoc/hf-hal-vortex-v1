Detailed Description

Continuous WS2812 exercise: colours, brightness, rainbow, breath, blink (infinite loop).

Use for bench bring-up when you want to stress LedManager + RMT over a long time. Flash: ./scripts/build_app.sh vortex_led_ws2812_cycle Release then ./scripts/flash_app.sh flash_monitor vortex_led_ws2812_cycle Release
