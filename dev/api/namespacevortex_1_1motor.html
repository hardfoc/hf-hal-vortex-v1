std::span< const ParamWrite >  image,
ApplyOptions  opt 
)
noexcept

Apply a parameter image: MOTOR_TYPE first, then the rest in image order.

Before MOTOR_TYPE is set, FW051V100 answers most axis parameters with REPLY_WRONG_TYPE (design §1.10), so it is written (and verified) before anything else. The rest goes kBatchChunk entries per pipelined batch. No allocation and a fixed stack footprint, whatever the image size.

Returns
The counts; ApplyResult::ok() when nothing was rejected or mismatched.
