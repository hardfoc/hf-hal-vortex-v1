Detailed Description

Bundle of host-side GPIO references for TMC9660 control pins.

These are the GPIO pins on the host MCU (e.g., ESP32) that connect to the TMC9660's control signals. They are required by the TMC9660 bootloader initialization sequence for hardware reset and fault monitoring.

Note
The BaseGpio instances must be pre-configured (pin number, direction) before being passed to the handler.
