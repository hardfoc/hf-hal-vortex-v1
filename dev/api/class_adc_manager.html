Detailed Description

Singleton manager for all analogue-to-digital channels on Vortex V1.

Provides a uniform API over the ESP32 internal ADC and the TMC9660 motor-controller ADC. Channels are registered from the pincfg X-MACRO table at initialisation and looked up by name or by functional enum.

Note
Call EnsureInitialized() once before any reads. All public methods are thread-safe (guarded by an internal RTOS mutex).
