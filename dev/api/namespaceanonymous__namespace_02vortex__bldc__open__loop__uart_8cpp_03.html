◆ kCruiseVelocity

constexpr int32_t anonymous_namespace{vortex_bldc_open_loop_uart.cpp}::kCruiseVelocity = 2500
constexpr

Cruise TARGET_VELOCITY (TMCL internal units, scaling factor 1). Lower than 5000 helps open-loop pull-in when the rotor lags the forced phi_e. 2500 in voltage mode = ~1 RPM at motor shaft / 0.1 RPM at output (10:1 reducer) — slow enough that even a heavy rotor can pull in, fast enough that motion is visible over a few-second cruise (~30° at motor shaft per second; output shaft tape mark moves ~3°/s). Bump up once spinning.

◆ kMinRampVelocity

constexpr int32_t anonymous_namespace{vortex_bldc_open_loop_uart.cpp}::kMinRampVelocity = 1000
constexpr

Floor used during ramp-up; bench observation is the chip rejects very small values when the OPENLOOP-CURRENT pipeline is fresh, so we never land between 0 and this value during the ramp itself (the final ramp-down explicitly writes 0 to stop). 1000 internal units ≈ 0.3 RPM at the bench's 7-pole-pair motor.

◆ kSafeOpenLoopCurrentMa

constexpr uint16_t anonymous_namespace{vortex_bldc_open_loop_uart.cpp}::kSafeOpenLoopCurrentMa = 1000
constexpr

Open-loop current. OPENLOOP_CURRENT (NR 46) is what the flux loop drives into the windings while the hardware ramper rotates phi_e. Must stay ≤ kMaxFluxCurrentMa and ≤ the 1.5 A MAX_TORQUE clamp. 1 A is a strong bring-up level for static friction; shorten cruise or lower if windings get hot.
