Detailed Description

LED management for the HardFOC Vortex V1 platform (single WS2812).

Single WS2812 LED on GPIO3 using RMT. Provides solid/blink/breath/ rainbow animations plus system status indication (boot, ready, error…).

Follows Flux-style lean singleton pattern. WS2812Strip and WS2812Animator are heap-allocated (driver objects), everything else is value-type.
