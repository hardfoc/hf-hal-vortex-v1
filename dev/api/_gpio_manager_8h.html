Detailed Description

GPIO management for the HardFOC Vortex V1 platform.

The Vortex board spans three GPIO chip types:

  • ESP32 internal GPIOs
  • PCAL95555 I²C GPIO expander
  • TMC9660 motor-controller GPIO bridge (GPIO17, GPIO18)

Uses a fixed-size std::array indexed by the platform mapping index (all pins known at compile time) instead of a heap-allocated unordered_map. String lookups iterate the constexpr mapping table.

Vortex TMC9660 / PCAL: motor-facing lines use PCAL_TMC_* (e.g. DRV_EN, RST, SPI mux, WAKE). TMC9660 GPIO17/18 are duplicated — read via PCAL inputs PCAL_TMC_GPIO17_EXP_IN / PCAL_TMC_GPIO18_EXP_IN (I²C expander), or configure/read the same nets through TMC_GPIO17 / TMC_GPIO18 once the handler bridge is registered.

Each entry stores a shared_ptr<BaseGpio> to accommodate the three different ownership models:

  • ESP32 pins: make_shared<EspGpio> (GpioManager owns)
  • PCAL95555 pins: shared_ptr from Pcal95555Handler::CreateGpioPin()
  • TMC9660 pins: non-owning aliasing shared_ptr (handler owns)
