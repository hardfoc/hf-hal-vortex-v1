Detailed Description

Motor controller focused test for ESP32.

Build twice from the same source: motor_controller_test (onboard SPI, default) and motor_controller_uart_test (UART before EnsureInitialized() via Vortex API).

Deep-dive testing of MotorController:

  • Handler access for onboard + external devices
  • visitDriver callback pattern
  • Device count and enumeration
  • Register read/write attempts
  • Device status queries
  • Statistics dump
