Detailed Description

One error catalog and one aggregated health snapshot for the whole Vortex HAL.

Each manager keeps its own error enum (CommError, MotorError, hf_gpio_err_t, ...). The facade maps them onto ManagerError, the shared catalog, so a caller can judge the board without knowing nine enums; the raw code travels alongside for the detail. Vortex::CollectDiagnostics() fills VortexBoardDiagnostics from counters the managers already hold: it makes no bus transfer and does not allocate, so it is safe from a periodic health task.

Ownership: value types. Thread safety: filled under the facade's lifecycle lock. MCU-free.
