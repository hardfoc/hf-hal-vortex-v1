# API reference

The API reference is generated by Doxygen from the headers in `lib/api`, `lib/managers` and the examples, and is
published with this site.

[Open the API reference](../api/index.html){ .md-button .md-button--primary }

Good starting points: the `Vortex` class (`lib/api/Vortex.h`) and the manager classes (`lib/managers/*.h`).

To build it locally, run Doxygen with the repository's configuration from the repository root and open the
`index.html` it writes:

```bash
git submodule update --init _config/doxygen-extensions/doxygen-awesome-css
doxygen _config/Doxyfile
open docs/_doxygen/html/index.html    # xdg-open on Linux
```
