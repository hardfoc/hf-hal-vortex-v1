# Pin map

Every functional pin and ADC channel of Vortex V1. The tables below are generated from the board's pin header,
[`hf_functional_pin_config_vortex_v1.hpp`](../../lib/core/hf-core-drivers/internal/hf-pincfg/src/hf_functional_pin_config_vortex_v1.hpp),
whose X-macro tables are the single source of pin truth ([ADR 0003](../adr/0003-pin-map-ownership.md)). CI fails
when the header changes and these tables are not regenerated, so they cannot drift.

How to read them:

- **Function** is the `HfFunctionalGpioPin` (or `HfFunctionalAdcChannel`) enum value. Code uses it, or the
  **Name** string, to find a pin: `vortex.gpio.Get(HfFunctionalGpioPin::PCAL_TMC_DRV_EN)` or
  `vortex.gpio.Get("GPIO_PCAL_TMC_DRV_EN")`.
- **Category**: *Core* pins are reserved for the system (boot, crystal, USB), *Comm* pins belong to a bus and are
  configured by its owner, *Gpio* pins are registered by [`GpioManager`](../managers/gpio.md).
- **Active** is the asserted level. For an active-low pin, `SetActive()` drives it low.

## Changing a pin

1. Edit the X-macro row in the pin header (in the [hf-pincfg](https://github.com/hardfoc/hf-pincfg) repository) and
   advance the `lib/core` submodule.
2. Run `python3 tools/docs/gen.py` and `python3 tools/figkit/build.py`, and commit the regenerated pages and figures
   with the submodule bump.
