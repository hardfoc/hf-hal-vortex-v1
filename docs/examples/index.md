# Examples

Every buildable app in [`examples/esp32`](../../examples/esp32). Each app is one `main/*.cpp` file selected by name
at build time; the table below is generated from the app list and each file's description, so it always matches the
code.

## Run one

```bash
cd examples/esp32
./scripts/build_app.sh <app> Release
./scripts/flash_app.sh flash_monitor <app> Release
```

`vortex_api_test` is the place to start: it initialises the whole HAL and exercises every manager. On a complete
bench (motor supply on, sensors fitted) turn on its strict checks in `idf.py menuconfig`, under
*Vortex API test (vortex_api_test)*, so that wiring or supply problems fail the test instead of only logging.

!!! warning "Motor benches move the motor"
    The apps under *Motor benches* spin a motor. Clamp the motor, set current limits for it, and read the
    [bench matrix](../../examples/esp32/docs/BENCH_MATRIX.md) and the
    [BLDC bring-up notes](../../examples/esp32/docs/BLDC_BRINGUP.md) first.
